# Modelos Oficiais Integrados

Os três documentos enviados foram cadastrados no acervo administrativo do UrbanDocs e associados às respectivas tipologias. Os arquivos permanecem no armazenamento privado do projeto, com suas versões registradas na base de dados.

| Tipologia UrbanDocs | Modelo associado | Principais campos e seções observados |
|---|---|---|
| `laudo_viabilidade` | **LV 28904/2026** | Dados de localização, endereço, lote, CAR, bairro, zoneamento, perímetro, relatório, legislação vigente, projeto urbanístico, aprovações, licenciamento, cartas de viabilidade e anexos. |
| `parecer_eiv` | **Parecer EIV — Lebi Construtora** | Processo, empreendimento, requerente, localização, bairro/gleba, lote, quadra, zoneamento, contextualização, parecer técnico e checklist detalhado de EIV. |
| `diretriz_loteamento` | **Diretriz de Loteamento — Processo 21337/2026** | Localização, lotes, coordenadas UTM, área, matrícula, zoneamento, sistema viário, infraestrutura, restrições urbanísticas, parcelamento, doações, proteção ambiental e documentos complementares. |

> Para preenchimento automático direto no conteúdo DOCX, o modelo pode receber marcadores no formato `{campo}`. Os campos de referência disponíveis incluem `protocolo`, `inscricao_imobiliaria`, `interessado`, `objeto`, `empreendimento`, `responsavel_tecnico`, `zoneamento`, `sistema_referencia` e os atributos extraídos das fontes territoriais.
